# Lesson 01 Notes

## What is Programming?

Programming is the process of writing instructions that tell a computer how to perform specific tasks.

---

## What is Procedural Programming?

Procedural Programming organizes code as a sequence of functions or procedures that execute one after another.

Examples:

- C
- Early BASIC
- Simple Python Scripts

---

## Why was OOP introduced?

As software became larger and more complex, procedural programming became difficult to maintain.

Object-Oriented Programming was introduced to improve:

- Reusability
- Maintainability
- Modularity
- Scalability
